Remote Desktop

I wanted something like AnyDesk to control my PC from my phone or laptop at home, but small enough to read and fully under my control. So I built one: a tiny Python program runs on the Windows PC, and you control it from any browser on your network, with nothing to install on the other device.

Download v1.0.1 (.zip)
Windows host · Python 3.10+ · MIT license · SHA-256: 56677eb299eb73e86ed3951558c7cb6d40215721785608122de686fbd36e7d73

⚠ For personal use on your own network. It is designed for your home network or a private VPN. Don't expose it to the internet with port forwarding (by default it refuses internet connections anyway).

Features

  • Live screen in the browser: only the parts that changed are sent, and text turns sharp when the screen is still
  • Full mouse and keyboard, any keyboard layout (accents and shortcuts work like a local keyboard)
  • Special keys menu (Windows key, Alt+Tab, Task Manager…) and fullscreen mode
  • Multiple monitors, quality / resolution / FPS controls
  • Clipboard in both directions, and send files by drag & drop
  • Works on phones and tablets: tap, long-press for right click, two-finger scroll, on-screen keyboard
  • A red banner on the PC whenever someone is connected, with a Disconnect button

Security

EncryptedEverything goes over HTTPS/WSS (a self-signed certificate is created on first run).
PasswordA random 12-character password is generated on first run and stored only as a salted hash.
Brute force5 wrong attempts lock that address out for 15 minutes.
Local onlyConnections from public internet addresses are refused; only LAN, localhost and private VPN addresses get in.
SessionsSigned, expiring, HttpOnly/Secure/SameSite=Strict cookies; Disconnect or a new password revokes them all.
Web hardeningStrict Content-Security-Policy, anti-clickjacking, Origin checks, safe upload filenames.

How to use

  1. Install Python on the PC you want to control (tick "Add python.exe to PATH").
  2. Unzip the download and double-click start.bat. The first run installs what it needs, then shows an address like https://192.168.x.x:8765 and your password (shown only once, so write it down).
  3. Right-click allow-firewall.bat → Run as administrator to allow it on your local network.
  4. On your phone or another computer, open that address, accept the certificate warning the first time (Advanced → Continue), and type the password.

How it works

The host captures the screen, splits it into 128-pixel tiles, and only JPEG-encodes the tiles that changed. The browser draws them on a canvas and confirms each frame, so a slow network lowers the frame rate instead of building up lag. Mouse and keyboard events go back over the same WebSocket and are injected with the Windows SendInput API. Keys are sent as physical scan codes, so the PC's own keyboard layout interprets them.

It runs at about 20–30 fps at 1080p on a home network. It has an automated test suite: security, input, clipboard, file transfer, and an end-to-end browser test.

Limitations

  • Windows PCs only as the host (any device can be the viewer).
  • No audio.
  • Windows doesn't let normal apps see or control the lock screen, Ctrl+Alt+Del or UAC prompts.
