This Website

This website is a project I built for improving my knowledge in both frontend and backend. I learnt the basics in college and wanted to try by myself!

It was also a challenge to set up my own domain and hosting, but I really enjoyed the process and definitely improved a lot while making it.

Github Repo

How it's made

  • Plain HTML, CSS and JavaScript: no framework and no build step, every page is just a file in the repo.
  • A hand-drawn notebook look: lined paper, hand-written fonts (Caveat Brush and Patrick Hand), wobbly ink borders and taped cards. It's the same style as my games, so the whole site feels like one notebook.
  • Free hosting on Cloudflare: every time I push to GitHub, the new version goes live at palomaliz.com.br in about a minute.
  • A tiny backend: a Cloudflare Worker with two small databases runs only the parts that need a server, the Loaf Tower leaderboard and the Chacrinha Jiu-Jitsu app. Everything else is static.
